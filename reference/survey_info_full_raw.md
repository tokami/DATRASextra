# Full survey information table

Extended version of `survey_info` with additional coverage and technical
details for each DATRAS survey.

## Usage

``` r
survey_info_full_raw
```

## Format

A data frame with columns:

- Survey:

  Survey code (e.g. NS-IBTS)

- Year:

  Years

- Quarter:

  Quarters

- Gear:

  Gear

- StatRec:

  ICES Statistical rectangle

- lon:

  Longitude

- lat:

  Latitude

## Source

ICES DATRAS metadata.
