# Wolffish survey data (example dataset)

Example ICES DATRAS data for *Anarhichas lupus* (wolffish) from survey
NS-IBTS Q1 in years 1991-2024.

## Usage

``` r
wolffish
```

## Format

A list of class 'datras_raw' with 3 elements:

- CA:

  Biological data

- HH:

  Survey level information

- HL:

  Length measurements

## Source

ICES DATRAS database <https://datras.ices.dk>
