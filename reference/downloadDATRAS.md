# Download DATRAS survey information

Download DATRAS survey information

## Usage

``` r
downloadDATRAS(
  surveys = NULL,
  years = NULL,
  download.missing.only = TRUE,
  download.ca = TRUE,
  use.php = FALSE,
  dir = NULL,
  verbose = TRUE
)
```

## Arguments

- surveys:

  NULL

- years:

  NULL

- download.missing.only:

  TRUE

- download.ca:

  TRUE

- use.php:

  FALSE

- dir:

  NULL

- verbose:

  TRUE
