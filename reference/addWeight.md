# Calculate weight by length classes and add to HH-records

Calculate weight by length classes and add to HH-records

## Usage

``` r
addWeight(d, to1min = TRUE, maxL = NULL, maxW = NULL)
```

## Arguments

- d:

  DATRASraw object

- to1min:

  divide by haul duration in minutes? (defaults to TRUE)

- maxL:

  x

- maxW:

  x

## Value

DATRASraw object
