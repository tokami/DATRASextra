# Clean data

Clean data

## Usage

``` r
clean(
  x,
  aphias = NULL,
  years = NULL,
  quarters = NULL,
  gears = NULL,
  impute.missing.depth = TRUE,
  correct.species = TRUE,
  do.fishglob = FALSE
)
```

## Arguments

- x:

  a DATRASraw object.

- aphias:

  x

- years:

  x

- quarters:

  x

- gears:

  x

- impute.missing.depth:

  TRUE

- correct.species:

  TRUE

- do.fishglob:

  FALSE

## Value

Cleaned DATRASraw object.
