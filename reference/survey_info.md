# Survey information table

Metadata for ICES bottom trawl surveys, including survey names, areas,
and available time ranges.

## Usage

``` r
survey_info
```

## Format

A data frame with columns:

- survey:

  Survey code (e.g. NS-IBTS)

- years:

  Years

- quarters:

  Quarters

- description:

  Description

## Source

ICES DATRAS metadata.
