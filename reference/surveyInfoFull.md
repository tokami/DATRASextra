# Full survey information table

Extended version of `surveyInfo` with additional coverage and technical
details for each DATRAS survey.

## Usage

``` r
surveyInfoFull
```

## Format

A data frame with columns:

- Survey:

  Survey code (e.g. NS-IBTS)

- Year:

  Years

- Quarter:

  Quarters

- Gear:

  Gear

- StatRec:

  ICES Statistical rectangle

- Hauls:

  Number of hauls

- lon:

  Longitude

- lat:

  Latitude

## Source

ICES DATRAS metadata.
