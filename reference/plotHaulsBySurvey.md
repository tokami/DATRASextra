# Plot hauls by survey

Plot hauls by survey

## Usage

``` r
plotHaulsBySurvey(
  plot.map = TRUE,
  fixed.scale = TRUE,
  col = hcl.colors(12, "YlOrRd", rev = TRUE),
  xlim = NULL,
  ylim = NULL
)
```

## Arguments

- plot.map:

  TRUE

- fixed.scale:

  TRUE

- col:

  colours

- xlim:

  NULL

- ylim:

  NULL
