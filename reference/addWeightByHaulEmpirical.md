# Calculate total biomass by haul using a and b, and add to HH-records

Calculate total biomass by haul using empirical a and b, and add to
HH-records

## Usage

``` r
addWeightByHaulEmpirical(d, to1min = TRUE)
```

## Arguments

- d:

  DATRASraw object

- to1min:

  divide by haul duration in minutes? (defaults to TRUE)

## Value

DATRASraw object
